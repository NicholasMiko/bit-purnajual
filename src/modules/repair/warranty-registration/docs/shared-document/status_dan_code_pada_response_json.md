#### Aturan Status dan Code pada Response JSON

| Code | Status            | Meaning                  |
| ---- | ----------------- | ------------------------ |
| `0`  | `Success`         | Seluruh proses berhasil  |
| `1`  | `Partial-Success` | Sebagian proses berhasil |
| `2`  | `Failed`          | Proses gagal             |
